# 🍽️ Cardápio Online Digital

Um **cardápio online interativo em HTML** projetado para modernizar o atendimento em restaurantes, bares e lanchonetes. O cliente escaneia um QR Code na mesa, visualiza os produtos e faz o pedido diretamente para o garçom.

---

## 🚀 Como Funciona?

1. **Escaneie o QR Code:** O cliente usa a câmera do celular para acessar a página.
2. **Navegue pelo Cardápio:** Uma interface limpa e responsiva exibe os pratos, bebidas e preços.
3. **Faça o Pedido:** O cliente escolhe os itens e faz o pedido diretamente ao garçom de forma rápida.

---

## ✨ Funcionalidades

- **Design Responsivo:** Totalmente otimizado para celulares e tablets.
- **Categorias Claras:** Separação intuitiva entre pratos principais, bebidas, sobremesas, etc.
- **Rápido e Leve:** Construído apenas com tecnologias web nativas, carregando instantaneamente.
- **Acessível:** Sem necessidade de baixar aplicativos.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Para a estruturação semântica do cardápio.
- **CSS3:** Para a estilização, cores e design responsivo (Mobile-First).
- **JavaScript (Opcional):** Para interações simples (como filtros de categorias ou soma de itens).

---

## 📦 Como Executar o Projeto

Como o projeto é feito em HTML puro, você não precisa instalar nenhuma dependência pesada.

1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para visualizá-lo no seu navegador.
